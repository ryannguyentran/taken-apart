# Taken Apart — Interactive Teardown Library

**Everything has something inside. We take it apart.**

The interactive companion to the **Taken Apart** YouTube channel: every machine featured on the channel, rebuilt as a fully interactive 3D simulation you can rotate, explode, isolate and cut open — running entirely in your browser, even offline.

**▶ Open the library: https://ryannguyentran.github.io/taken-apart/**

Tap a poster to open its simulation right on the page. Every simulation has its own 🇻🇳/🇬🇧 language switch.

## In the library now

| Machine | What you can do |
|---|---|
| V8 Engine | Four-stroke cycle, firing order 1-8-4-3-6-5-7-2, live RPM gauges, engine sound |
| Cessna 337 Landing Gear | Retract / extend the gear, watch the linkage and hydraulics work |
| Strandbeest | Theo Jansen's walking machine — the Jansen linkage, step by step |
| Vintage Table Radio | Cord-drive tuning, dual-gang capacitor, AM/FM behaviour |
| CRT Television | One electron beam paints the whole picture — 625 lines |
| Inside the Earth | Five layers, one 6,371 km dive from the crust to the core (PREM data) |

Every model is driven by the real mathematics of the mechanism, with measured, cross-checked data — the same simulations used to produce the channel's videos.
